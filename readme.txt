== Description ==

Universal Product Reviews provides portable WooCommerce product-review
operations — invitations, guest authorization, moderation, and retention.

== Installation ==

1. Upload the plugin ZIP via Plugins → Add New → Upload, or extract to
   `wp-content/plugins/universal-product-reviews/`.
2. Activate the plugin.
